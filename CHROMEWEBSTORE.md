# Chrome Web Store Listing — WA Web Privacy Blur

> Last Updated: 2026-06-08

## Store Listing

**Extension Name**
WA Web Privacy Blur

**Short Description**
Memburamkan pesan, foto profil, preview chat, dan media di WhatsApp Web untuk menjaga privasi dari tatapan orang sekitar.

**Detailed Description**
WA Web Privacy Blur adalah alat bantu keamanan privasi premium yang dirancang khusus untuk memburamkan bagian-bagian sensitif di WhatsApp Web Anda agar tidak mudah diintip oleh orang lain di sekitar Anda (shoulder surfing).

Fitur Utama:
- All messages in chat: Memburamkan seluruh isi obrolan aktif.
- Last messages preview: Memburamkan teks pratinjau pesan terakhir di daftar chat sebelah kiri.
- Media preview & gallery: Memburamkan foto, video, dan galeri media agar tidak langsung terlihat sebelum kursor diarahkan.
- Text input: Memburamkan teks yang sedang Anda ketik di kolom pesan (otomatis jelas kembali saat kursor berada di kolom tersebut).
- Profile pictures & Contact names: Menyembunyikan identitas lawan bicara dengan memburamkan foto profil dan nama kontak.
- Auto-Lock Screen on Idle: Mengunci dan memburamkan seluruh layar WhatsApp Web otomatis jika Anda meninggalkan PC Anda selama durasi menit yang ditentukan.
- Unblur on hover: Arahkan kursor Anda ke bagian yang buram untuk langsung melihat isinya dengan transisi yang halus atau instan.

Cara Menggunakan:
1. Pasang ekstensi ini ke Google Chrome Anda.
2. Buka tab baru dan buka WhatsApp Web (https://web.whatsapp.com/).
3. Klik ikon ekstensi di toolbar kanan atas untuk membuka panel kontrol.
4. Aktifkan sakelar "Aktifkan Blur" dan pilih elemen mana saja yang ingin Anda sembunyikan.
5. Gunakan slider (dengan mengeklik tombol gear di sebelah pengaturan) untuk menyetel tingkat kekaburan (px) dan durasi kunci layar otomatis (idle time).

Ekstensi ini berjalan sepenuhnya secara lokal di komputer Anda tanpa mengirim data apa pun ke server eksternal, menjamin kerahasiaan penuh chat Anda.
